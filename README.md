# Student Management System

A production-oriented CLI-based Student Management System built with Python.

## Project Goals

This project is designed to demonstrate:

* Clean Architecture
* Object-Oriented Programming
* SOLID principles
* Separation of Concerns
* Repository Pattern
* Dependency Injection
* Validation
* Authentication
* Logging
* Exception Handling
* Unit and Integration Testing
* Professional Python project structure

## Initial Storage

The first version uses CSV files.

The architecture is designed so that the storage implementation can later be replaced with technologies such as:

* SQLite
* PostgreSQL
* MongoDB

without changing the core business logic.
